# Web Search Skill

当用户需要查找互联网上的信息时使用此技能。

## 使用场景

- 查找最新新闻或事件
- 搜索技术文档或教程
- 查询实时信息（天气、股票等概念性信息）

## 使用方法

调用 `web_search` 工具，传入搜索关键词。返回结果为搜索摘要列表。

## 注意事项

- 优先使用精确的搜索关键词
- 对搜索结果保持批判性思维，注意信息可靠性
- 如果一次搜索结果不理想，尝试调整关键词重新搜索
